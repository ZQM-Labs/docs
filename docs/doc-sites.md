# All Doc Sites

docs.zqmlabs.com is the front door. Each ZQM Labs project keeps its own documentation site — they stay where they are; this page is the index.

## Game & organizer docs

| Site | What it holds |
|---|---|
| [Organizer Toolkit](https://organize.zqmlabs.com) | The full organizer guides: setup checklist, print specs, QR sign generator, day-of troubleshooting |
| [Quest Packs](https://packs.zqmlabs.com) | Ready-to-play quest packs, including the free 6-stop sample quest |
| [Quest Authoring](https://quests.zqmlabs.com) | The quest-pack format spec, authoring guide, and validator — make your own packs |
| [Playtests](https://playtests.zqmlabs.com) | Playtest protocols, templates, and how feedback shapes the game |
| [Z's Zoo](https://zoo.zqmlabs.com) | The bestiary — a field guide to the creatures of the quests |
| [zqmlabs.com](https://zqmlabs.com) | The main site: games directory, hosting tiers, FAQ |
